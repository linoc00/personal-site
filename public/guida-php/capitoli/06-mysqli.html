6  Interazione tra PHP e MySQL con MySQLi

6.1 PHP e MySQL

Uno degli utilizzi principali di PHP è la realizzazione di siti web dinamici che leggono e modificano dati memorizzati in un database.

Il funzionamento generale è il seguente:

Browser  <-->  Pagina PHP  <-->  Database MySQL

Il browser invia una richiesta alla pagina PHP. La pagina PHP comunica con il database, elabora i dati ricevuti e genera la risposta HTML da mostrare all’utente.

PHP può lavorare con diversi DBMS, per esempio MySQL, MariaDB, PostgreSQL e Microsoft SQL Server. In questo capitolo ci concentreremo su MySQL e sull’estensione MySQLi.

NotaPercorso del capitolo

Il capitolo segue l’ordine didattico delle slide fornite: introduzione a MySQLi, connessione al database, esecuzione delle query, lettura dei risultati e prepared statement.

6.2 L’estensione MySQLi

MySQLi significa MySQL Improved, cioè “MySQL migliorato”. È l’estensione di PHP che mette a disposizione funzioni e metodi per comunicare con un database MySQL o MariaDB.

MySQLi può essere usata in due modi:

  • con l’approccio procedurale, usando funzioni come mysqli_connect() e mysqli_query();

  • con l’approccio orientato agli oggetti, usando oggetti e metodi come new mysqli() e $mysqli->query().

I due approcci permettono di svolgere le stesse operazioni. Cambia soltanto il modo in cui vengono scritte le istruzioni.

Operazione Approccio procedurale Approccio a oggetti
Connessione mysqli_connect() new mysqli()
Esecuzione di una query mysqli_query() $mysqli->query()
Lettura di una riga mysqli_fetch_assoc() $result->fetch_assoc()
Chiusura mysqli_close() $mysqli->close()

MySQLi supporta anche strumenti più avanzati, come le transazioni e i prepared statement. In questo capitolo approfondiremo soprattutto i prepared statement, perché permettono di inserire dati variabili nelle query in modo corretto e sicuro.

AvvisoAttenzione alla vecchia estensione mysql

Le vecchie funzioni mysql_connect() e mysql_query() non devono più essere utilizzate. Nei programmi moderni si usano MySQLi oppure PDO.

6.3 Il database degli esempi

Negli esempi utilizzeremo il database scuola e la tabella utente.

CREATE DATABASE IF NOT EXISTS scuola

USE scuola;

CREATE TABLE IF NOT EXISTS utente (
    id INT AUTO_INCREMENT PRIMARY KEY,
    cognome VARCHAR(50) NOT NULL,
    nome VARCHAR(50) NOT NULL,
    login VARCHAR(50) NOT NULL UNIQUE
);

INSERT INTO utente (cognome, nome, login)
VALUES
    ('Rossi', 'Mario', 'mrossi'),
    ('Bianchi', 'Anna', 'abianchi'),
    ('Verdi', 'Luca', 'lverdi');

La tabella contiene quattro campi:

  • id: identificativo numerico assegnato automaticamente;
  • cognome: cognome dell’utente;
  • nome: nome dell’utente;
  • login: nome utilizzato per accedere all’applicazione.

6.4 Connessione a MySQL con MySQLi

Per collegarsi al database servono quattro informazioni:

  • host: il computer sul quale è in esecuzione MySQL; in locale si usa normalmente localhost;
  • username: il nome dell’utente MySQL;
  • password: la password dell’utente MySQL;
  • database: il nome del database da utilizzare.

Negli esempi seguenti i valori di username e password devono essere sostituiti con quelli configurati nel proprio ambiente di lavoro.

Connessione con approccio procedurale

Nell’approccio procedurale si utilizza la funzione mysqli_connect():

<?php
$host = "localhost";
$user = "username"; // di default impostato root
$password = "password";
$database = "scuola";

try {
    $connessione = mysqli_connect(
        $host,
        $user,
        $password,
        $database
    );

    mysqli_set_charset($connessione, "utf8mb4");

    echo "Connessione riuscita";
} catch (mysqli_sql_exception $errore) {
    die("Connessione non riuscita");
}

mysqli_close($connessione);
?>

La variabile $connessione rappresenta il collegamento aperto con MySQL. Verrà usata nelle successive operazioni sul database.

Il blocco catch viene eseguito solamente se la connessione fallisce. In questo caso il programma termina mostrando un messaggio semplice.

Connessione con approccio orientato agli oggetti

Nell’approccio orientato agli oggetti si crea un’istanza della classe mysqli:

<?php
$host = "localhost";
$user = "username";
$password = "password";
$database = "scuola";

try {
    $mysqli = new mysqli(
        $host,
        $user,
        $password,
        $database
    );

    $mysqli->set_charset("utf8mb4"); //il simbolo -> permette di accedere ai metodi dell'oggetto

    echo "Connessione riuscita";
} catch (mysqli_sql_exception $errore) {
    die("Connessione non riuscita");
}

$mysqli->close();
?>

In questo caso $mysqli è un oggetto che rappresenta la connessione. Le operazioni vengono richiamate con l’operatore ->.

ConsiglioQuale approccio scegliere?

Per iniziare è possibile usare l’approccio procedurale, che assomiglia alle funzioni PHP già studiate. È comunque importante saper riconoscere anche l’approccio a oggetti, perché è molto diffuso negli esempi e nella documentazione.

6.5 Eseguire una query

Il lavoro con una query può essere diviso in quattro fasi.

Fase Operazione
1. Preparazione si scrive il comando SQL
2. Esecuzione il comando viene inviato a MySQL
3. Estrazione si leggono le righe restituite
4. Formattazione i dati vengono inseriti nella pagina HTML

L’estrazione serve soprattutto con le query SELECT. La formattazione dipende invece dal risultato che si vuole mostrare nella pagina.

Prima fase: preparazione

La query viene memorizzata in una normale stringa PHP:

$query = "SELECT id, cognome, nome FROM utente";

È possibile aggiungere condizioni e ordinamenti:

$query = "SELECT id, cognome, nome
          FROM utente
          WHERE id = 2
          ORDER BY cognome";

Quando la query deve contenere un valore ricevuto da un form, non bisogna concatenarlo direttamente alla stringa. In seguito vedremo come usare un prepared statement.

Seconda fase: esecuzione

Con l’approccio procedurale la query viene eseguita con mysqli_query():

$result = mysqli_query($connessione, $query);

Con l’approccio a oggetti si utilizza il metodo query():

$result = $mysqli->query($query);

Il comportamento dipende dal tipo di query:

  • una SELECT restituisce un insieme di righe chiamato result set;

  • una INSERT, UPDATE o DELETE restituisce l’esito dell’operazione.

Terza fase: estrazione

Le righe del result set possono essere lette una alla volta.

Con mysqli_fetch_array() è possibile scegliere il tipo di array restituito:

Modalità Tipo di array Esempio di accesso
MYSQLI_NUM indici numerici $riga[0]
MYSQLI_ASSOC indici con il nome dei campi $riga["id"]
MYSQLI_BOTH entrambi i tipi di indice $riga[0] oppure $riga["id"]

Esempio con un array numerico:

while ($riga = mysqli_fetch_array($result, MYSQLI_NUM)) {
    echo "ID: " . $riga[0] . " ";
    echo "Cognome: " . $riga[1] . " ";
    echo "Nome: " . $riga[2] . "<br>";
}

Esempio con un array associativo:

while ($riga = mysqli_fetch_array($result, MYSQLI_ASSOC)) {
    echo "ID: " . $riga["id"] . " ";
    echo "Cognome: " . $riga["cognome"] . " ";
    echo "Nome: " . $riga["nome"] . "<br>";
}

La funzione mysqli_fetch_assoc() restituisce direttamente un array associativo:

while ($riga = mysqli_fetch_assoc($result)) {
    echo $riga["cognome"] . " " . $riga["nome"] . "<br>";
}

L’array associativo è spesso più leggibile, perché il nome del campo indica chiaramente quale dato si sta utilizzando.

Estrazione con l’approccio a oggetti

Con l’approccio a oggetti si usano i metodi del result set:

while ($riga = $result->fetch_assoc()) {
    echo $riga["cognome"] . " " . $riga["nome"] . "<br>";
}

È possibile usare anche:

$riga = $result->fetch_array(MYSQLI_NUM);
$riga = $result->fetch_array(MYSQLI_ASSOC);
$riga = $result->fetch_array(MYSQLI_BOTH);

Quarta fase: formattazione

La formattazione consiste nel costruire l’HTML da mostrare nel browser. Per esempio:

while ($riga = mysqli_fetch_assoc($result)) {
    $cognome = htmlspecialchars($riga["cognome"]);
    $nome = htmlspecialchars($riga["nome"]);

    echo "<p>$cognome $nome</p>";
}

htmlspecialchars() evita che eventuali caratteri speciali presenti nei dati vengano interpretati come codice HTML.

6.6 Numero di righe restituite

Una query può essere corretta ma non trovare alcuna riga. Per conoscere il numero di righe restituite da una SELECT si usa:

// Approccio procedurale
$numeroRighe = mysqli_num_rows($result);

oppure:

// Approccio a oggetti
$numeroRighe = $result->num_rows;

Il valore può essere controllato prima di leggere il result set:

if (mysqli_num_rows($result) === 0) {
    echo "Nessun utente trovato";
} else {
    while ($riga = mysqli_fetch_assoc($result)) {
        echo $riga["login"] . "<br>";
    }
}

6.7 Numero di righe modificate

Dopo una query INSERT, UPDATE o DELETE, è possibile sapere quante righe sono state modificate.

// Approccio procedurale
$numeroRighe = mysqli_affected_rows($connessione);
// Approccio a oggetti
$numeroRighe = $mysqli->affected_rows;
Notanum_rows e affected_rows

num_rows si usa per contare le righe restituite da una SELECT. affected_rows si usa per contare le righe modificate da INSERT, UPDATE o DELETE.

6.8 Chiudere la connessione

Al termine delle operazioni la connessione può essere chiusa.

// Approccio procedurale
mysqli_close($connessione);
// Approccio a oggetti
$mysqli->close();

Se è stato creato un result set, è possibile liberare anche la memoria utilizzata:

// Approccio procedurale
mysqli_free_result($result);
// Approccio a oggetti
$result->free();

6.9 Esempio completo con approccio procedurale

Il seguente esempio riunisce le quattro fasi presentate.

<?php
try {
    // Apertura della connessione
    $connessione = mysqli_connect(
        "localhost",
        "root",
        "",
        "scuola"
    );
    mysqli_set_charset($connessione, "utf8mb4");

    // 1. Preparazione della query
    $query = "SELECT id, cognome, nome, login
              FROM utente
              ORDER BY cognome, nome";

    // 2. Esecuzione della query
    $result = mysqli_query($connessione, $query);

    // 3. Estrazione e 4. formattazione
    while ($riga = mysqli_fetch_assoc($result)) {
        $id = (int) $riga["id"];
        $cognome = htmlspecialchars($riga["cognome"]);
        $nome = htmlspecialchars($riga["nome"]);
        $login = htmlspecialchars($riga["login"]);

        echo "<p>";
        echo "ID: $id - $cognome $nome - Login: $login";
        echo "</p>";
    }

    mysqli_free_result($result);
    mysqli_close($connessione);
} catch (mysqli_sql_exception $errore) {
    echo "Errore durante l'accesso al database";
}
?>

6.10 Esempio completo con approccio orientato agli oggetti

// definizione delle variabili d'ambiente
$host = "localhost"; // in alternativa anche 127.0.0.1
$user = "root";
$password = "";
$database = "scuola";

try {
    // Apertura della connessione
    $mysqli = new mysqli(
        $host,
        $user,
        $password,
        $database
    );
    $mysqli->set_charset("utf8mb4"); //il simbolo -> permette di accedere ai metodi dell'oggetto
    echo "Connessione riuscita";

    // 1. Preparazione della query
    $query = "SELECT id, cognome, nome, login
              FROM utente
              ORDER BY cognome, nome";

    // 2. Esecuzione della query
    $result = $mysqli->query($query);

    // 3. Estrazione e 4. Formattazione
    while ($riga = $result->fetch_assoc()) {
        $id = (int) $riga["id"];
        $cognome = htmlspecialchars($riga["cognome"]);
        $nome = htmlspecialchars($riga["nome"]);
        $login = htmlspecialchars($riga["login"]);

        echo "<p>";
        echo "ID: $id - $cognome $nome - Login: $login";
        echo "</p>";
    }
    
} catch (mysqli_sql_exception $errore) {
    die("Connessione non riuscita");
}

$mysqli->close();

6.11 Prepared statement

Un prepared statement è una query nella quale la struttura SQL viene separata dai valori utilizzati.

Al posto del valore si inserisce un punto interrogativo ?, chiamato placeholder:

SELECT cognome, nome
FROM utente
WHERE id = ?

Il valore viene associato al placeholder in un secondo momento. In questo modo un dato ricevuto dall’utente non può modificare la struttura della query.

I prepared statement aiutano quindi a prevenire gli attacchi di SQL injection, nei quali un utente tenta di inserire comandi SQL all’interno di un campo di input.

Prepared statement con approccio a oggetti

<?php
$id = 2;

// Preparazione della query
$stmt = $mysqli->prepare(
    "SELECT cognome, nome FROM utente WHERE id = ?"
);

// Associazione del valore al placeholder
$stmt->bind_param("i", $id);

// Esecuzione
$stmt->execute();

// Associazione delle colonne restituite alle variabili PHP
$stmt->bind_result($cognome, $nome);

// Lettura del risultato
if ($stmt->fetch()) {
    echo $cognome . " " . $nome;
} else {
    echo "Utente non trovato";
}

$stmt->close();
?>

Le operazioni fondamentali sono:

  1. prepare(): prepara la struttura della query;
  2. bind_param(): associa i valori ai placeholder;
  3. execute(): esegue la query;
  4. bind_result(): collega le colonne restituite a variabili PHP;
  5. fetch(): legge una riga;
  6. close(): chiude lo statement.

Tipi dei parametri

Il primo argomento di bind_param() indica il tipo del valore associato:

Carattere Tipo di dato
i numero intero
d numero decimale
s stringa
b dato binario

Se i parametri sono più di uno, i caratteri vengono scritti nello stesso ordine dei valori:

$stmt = $mysqli->prepare(
    "INSERT INTO utente (cognome, nome, login)
     VALUES (?, ?, ?)"
);

$stmt->bind_param("sss", $cognome, $nome, $login);

La stringa "sss" indica che i tre valori sono stringhe.

Prepared statement con approccio procedurale

Lo stesso esempio può essere scritto con le funzioni procedurali:

<?php
$id = 2;

$stmt = mysqli_prepare(
    $connessione,
    "SELECT cognome, nome FROM utente WHERE id = ?"
);

mysqli_stmt_bind_param($stmt, "i", $id);
mysqli_stmt_execute($stmt);
mysqli_stmt_bind_result($stmt, $cognome, $nome);

if (mysqli_stmt_fetch($stmt)) {
    echo $cognome . " " . $nome;
} else {
    echo "Utente non trovato";
}

mysqli_stmt_close($stmt);
?>

6.12 Errori negli statement

Se uno statement non viene eseguito correttamente, MySQLi mette a disposizione il numero e il messaggio dell’errore.

Informazione Approccio procedurale Approccio a oggetti
Numero dell’errore mysqli_stmt_errno($stmt) $stmt->errno
Messaggio dell’errore mysqli_stmt_error($stmt) $stmt->error

Durante lo sviluppo queste informazioni possono aiutare a individuare il problema. In un sito pubblicato non è opportuno mostrare al visitatore i dettagli tecnici del database.

6.13 Riepilogo

  • MySQLi permette a PHP di comunicare con MySQL o MariaDB.
  • È possibile usare uno stile procedurale oppure uno stile orientato agli oggetti.
  • Per collegarsi servono host, username, password e nome del database.
  • Una query può essere divisa in preparazione, esecuzione, estrazione e formattazione.
  • mysqli_fetch_assoc() legge una riga come array associativo.
  • num_rows conta le righe restituite; affected_rows conta le righe modificate.
  • I prepared statement separano la query SQL dai valori e aiutano a prevenire la SQL injection.

  7. Creare un prepared statement per inserire cognome, nome e login di un nuovo utente.
